> 只总结**我自己写错的**语法点。按**语法点**分类(不按文章),每条有「我写的 ✗」和「正确 ✓」,后面标出处。
>
> 新文章里出现**已有的语法点**,只在那一节补例子和出处;出现**新的语法点**,才加新的一节。
>
> 出处写法:`11847-1` = 11847 第 1 次中译英,`382-1` = 382 第 1 次。

## 1. 词尾决定词性

| 词性 | 常见词尾 | 我写错的 |
| --- | --- | --- |
| 形容词 | -able、-ible、-ing、-ed | ✗ acceptabled → ✓ acceptable;✗ unimaged → ✓ unimaginable;✗ development countries → ✓ developing countries;✗ the isolate people → ✓ the isolated people |
| 名词 | -ment、-tion、-ity | ✗ in employe → ✓ in employment;✗ unqueite → ✓ inequality |
| 过去分词 | -ed | ✗ has transformat → ✓ has transformed;✗ must be narrow → ✓ must be narrowed;✗ could be threated → ✓ could be threatened |

- 介词后面要名词:in **employment**。
- 形容词后面不加 -ed:**acceptable**。
- **形容词不能当名词用(382-1、407-1):** ✗ `play games on electronic` / `use electronic` → ✓ `on electronic **devices**`;✗ `harm children's eyes and physical` → ✓ `eyes and **bodies**` / `physical **health**`。注意 electronics 是「电子学」(学科),不是「电子设备」。
- **名词不能当形容词用(401-1):** ✗ `the system is not security` → ✓ `not **secure**`。is / are 后面描述「怎么样」,要用形容词。
- **动词和名词用混(407-1):** ✗ `negative affects` → ✓ `negative **effects**`。**affect 是动词,effect 是名词**;✗ `are more efficiency` → ✓ `work more **efficiently**`(修饰动词用副词);✗ `afraid to social with others` → ✓ `afraid to **socialise** with others`(social 是形容词,「交往」用动词)。
- **修饰名词要用形容词(409-1):** ✗ `its truely size` → ✓ `its **true** size`(副词 truly 不能修饰名词);✗ `economy growth` → ✓ `**economic** growth`。
- **3946-1 词性大爆发(一篇 6 处),同一个错误模式:** 介词 / 形容词位置上放了名词。
  - ✗ `in modern **social**` → ✓ `in modern **society**`(social 形,society 名,本篇错 2 次)
  - ✗ `**pleasure** home atmosphere` → ✓ `**a pleasant** family atmosphere`
  - ✗ `**harmony** home atmosphere` → ✓ `**a harmonious** family atmosphere`
  - ✗ `the **lost** of faulty production` → ✓ `the **loss** from faulty goods`(lost 是 lose 的过去式,名词是 loss)
  - ✗ `robots could **product** more **productions**` → ✓ `robots can **produce** more **products**`(product 名 → produce 动;production 不可数)
  - ✗ `are efficitive and accruated` → ✓ `are **efficient and accurate**`
- **3947-1 又错 2 处:**
  - ✗ `**advantage** alien creature` → ✓ `**advanced** alien life forms`(advantage 是名词「优势」,形容词「先进的」= advanced)
  - ✗ `more **understand** of aliens` → ✓ `a better **understanding of** alien creatures`(understand 是动词,名词 = understanding)

| 名词 | 形容词 |
| --- | --- |
| security | secure |
| efficiency | efficient(副词 efficiently) |
| popularity | popular |
| importance | important |
| economy | economic |
| society | social |
| pleasure | pleasant |
| harmony | harmonious |
| loss | lose(动)/ lost(过去式) |
| advantage(优势) | advanced(先进的) |
| understanding(理解,名) | understand(动) |
| effect(名) | affect(动) |

出处:11847-1、382-1、401-1、407-1、409-1、3946-1、3947-1

| 不熟悉的 | unsimilar | **unfamiliar** |
| 不平等 | unqueite | **inequality** |
| 处于不利地位的 | disadvanted | **disadvantaged** |

## 3. 被动语态:be + 过去分词

| ✗ | ✓ |
| --- | --- |
| the divide can be and must be **narrow** | the divide can be, and must be, **narrowed** |
| shouldn't be xxx | shouldn't be **tolerated** |
| should be **simplely** accepted | should be **simply** accepted / should **simply** be accepted |
| children's health could be **threated** | could be **threatened** |
| if meetings are **hold** online | are **held** |
| company secrets can be **steal** | can be **stolen** |
| the unnecessary cost **who cause by** human | the unnecessary costs **caused by** human error |
| once the message **was send** out | once a message **is sent** out |

副词放在 be 前面或后面都对;放在情态动词和 be 之间(should **simply** be accepted)更常见。

**不规则动词的过去分词要背(401-1 两个都错在这里):**

| 原形 | 过去式 | 过去分词 |
| --- | --- | --- |
| hold | held | **held** |
| steal | stole | **stolen** |
| build | built | **built** |
| make | made | **made** |
| take | took | **taken** |
| keep | kept | **kept** |

**who / which 的分工(3946-1):** who 只能指人,指物用 which / that;过去分词可以直接作后置定语,不需要关系代词:✗ `costs who cause by human` → ✓ `costs **caused by** human error`(= costs which are caused by …)。

**once 引导的普遍规律用一般现在时的被动(3947-1):** ✗ `Once the message **was send** out` → ✓ `Once a message **is sent** out`。send → sent(过去分词);「一旦……就……」讲客观规律,不用过去时。

出处:11847-1、382-1、401-1、3946-1、3947-1

## 5. 介词后面用 doing

| ✗ | ✓ | 出处 |
| --- | --- | --- |
| via work at home | **by working** at home | 11847-1 |
| prevent them from **communicate** with friends, widening … and **develop** … | prevent them from **communicating** with friends, widening … and **developing** … | 382-1 |
| Using computer frequally, they will … | **By using** computers frequently, they will … | 382-1 |
| to prevent somthing from **happen** | to prevent this from **happening** | 401-1 |
| can … come back to workplae **and don't waste** time | can … come back to their workplace **without wasting** time | 401-1 |
| is harmful to **develop** children's social ability | is harmful to **the development of** children's social skills | 407-1 |
| a way **boosting** economy growth | a way **of promoting** economic growth | 409-1 |
| are used to **use** robots | **get used to robots doing** chores / get used to **using** robots | 3946-1 |
| helpful **to create** | helpful **in creating** | 3946-1 |

- by doing = 通过……的方式。
- **介词后面并列几个动作,每一个都要 -ing**(382-1 中间的 widening 对了,前后两个错了)。
- **to 不一定是不定式符号,也可能是介词**:look forward to doing、**be / get used to doing**(3946-1)、harmful to sth(407-1),后面接名词或 doing。
- **「做某事的方式」= a way of doing / a way to do**(409-1),不能直接 a way doing。
- **be helpful in doing sth**(3946-1),介词用 in,不用 to。

**by 后面接名词时要小心(11847-2):**

| 结构 | 意思 | 例子 |
| --- | --- | --- |
| by + doing | 通过做某事 | kept their jobs **by working** at home ✓ |
| by + 交通 / 通讯方式(不加冠词) | 乘…、用… | by bus、by email、by phone |
| through / via + 名词 | 通过某个渠道 | continued studying **through** online courses(✗ by online courses) |

出处:11847-1、11847-2、382-1、401-1、407-1、409-1、3946-1

## 7. 动词作主语用 doing

中文「长时间看屏幕会……」「使用新技术能……」,主语是一个动作,英文要变成 **doing**。

| ✗ | ✓ |
| --- | --- |
| **Long time startiing at screen** may cause eye strain | **Staring at screens for a long time** may cause eye strain |
| **long time to use** these new technology could harm … | **using** these new technologies **for a long time** could harm … |
| Although **use** new tenologies can develop … | Although **using** new technologies can develop … |
| **master** how to use new technology, **it** is an important skill | **mastering** how to use new technology **is** an important skill |

「长时间」= for a long time,**放在 doing 短语的最后**。

407-1 那句还有一个问题:一个句子不能有 master 和 it 两个主语,把动词变成 mastering 之后,it 就多余了。

出处:382-1、407-1

## 8. 动词 + 介词搭配

| ✗ | ✓ | 出处 |
| --- | --- | --- |
| invest basic infrastructure | invest **in** basic infrastructure | 11847-1、11847-2 |
| link that **with** long screen time | link this **to** too much screen time | 382-1 |
| spending free time **in** new technology | spend free time **on** new technologies | 382-1 |
| it will harm **to** children eyes | it can harm children's eyes | 382-1 |
| hold meetings **in** headquarte | hold meetings **at** their headquarters | 401-1 |
| company secrets can be stolen **on** online meetings | … stolen **during** online meetings | 401-1 |
| hackers may break into **and** steal … | hackers may break into **it** and steal … | 401-1 |
| **it might occur something** | **some problems might occur** / something might happen | 401-1 |
| attractive **for** children | attractive **to** children | 407-1 |
| cause negative affects **for** … | **have** negative effects **on** … | 407-1 |
| play **computer and tablet** | play **on computers and tablets** | 407-1 |
| disagree **the point / the viewpoint** | disagree **with this view** | 409-1 |
| play **specific role who** come from … | play **the role of people** from … | 409-1 |
| argue **with** the division of chores | argue **about** the division of chores | 3946-1 |
| take charge **work** | take charge **of the** work | 3946-1 |
| **xx** the loss(承担) | **bear** the loss / bear the cost | 3946-1 |
| learn **technology** from them | learn **from their** technology | 3947-1 |
| Europeans arrive **Americas** | Europeans arrived **in the** Americas | 3947-1 |
| put humanity **at risks** / **at the** position | put humanity **at risk** / **in the** same position | 3947-1 |

- invest money **in** sth;link A **to** B;spend time / money **on** sth。
- **harm、affect、damage 后面直接接宾语,不加 to。**
- **break into 后面必须有宾语**(break into **it** / **the system**)。
- **occur、happen 是不及物动词,后面不能接宾语。** 中文「会出现问题」,英文要让「问题」做主语:✓ `Problems might occur.` ✗ `It might occur problems.`
- **「对……有影响」= have an effect on;「对某人有吸引力」= attractive to sb。**
- **disagree 是不及物动词,必须加 with**(409-1 一篇漏了 2 次):disagree **with** sth / sb。
- **「扮演……的角色」= play the role of sb**;who 只能指人,不能指 role。
- **argue with + 人,argue about + 事**(3946-1);**take charge of + 宾语**(3946-1);「承担成本 / 损失」= **bear** the cost / loss。
- **固定搭配整体记(3947-1):at risk(不加 s)、in the same position(介词用 in)、arrive in + 大地方、learn from sth。**

出处:11847-1、11847-2、382-1、401-1、407-1、409-1、3946-1、3947-1

## 9. 大作文的时态

| 用在哪里 | 时态 | 例子 |
| --- | --- | --- |
| 讨论现状 | 一般现在时 | many people **are** left behind;elderly people **are** put off(✗ were) |
| 到现在为止的变化 | 现在完成时 | technology **has transformed** our lives |
| 过去的例子 | 一般过去时 | during the pandemic, students **continued** … and employees **kept** …(✓ 你用对了) |
| 有过去时间 | 一般过去时 | all of which **were** unimaginable a generation ago(✗ is) |
| 讲普遍情况 | 一般现在时 | Big companies usually **have** branches around the world(✗ built) |
| will 后面 / 时间状语从句 | 动词原形 | they will **fall** behind(✗ fell);when children **grow up**(✗ grown) |
| 假设的结果 | would + 动词原形 | cities **would lose** a way(✗ lost) |
| 历史例子 | 一般过去时 | when Europeans **arrived** …, native peoples **suffered** … and **lost** their land(✗ arrive / suffer) |

有 usually、often、always 的句子,一般用现在时。

**grown 是 grow 的过去分词,不能单独用在 after / when 后面**(407-1):「孩子长大后」= when children **grow up**。fell 是 fall 的过去式,will 后面要用原形 fall。

**讲假设的、还没发生的结果用 would + 原形**(409-1):✗ `city lost a way` → ✓ `cities **would lose** a way`,不能用过去式 lost。

**will 和 would 分工(3946-1):** 对未来的**确定性预测**用 will:✗ `more people **would** lose their jobs` → ✓ `more people **will** lose their jobs`;would 用于假设(if I were …, I would …)或委婉语气,不能全篇代替 will。

**历史例子必须用一般过去时(3947-1,一篇错 3 处):** ✗ `when Europeans **arrive** …, residents **suffer** …, losing their land` → ✓ `when Europeans **arrived** …, native peoples **suffered** … and **lost** their land`。看到「历史上、曾经、……的时候」就切换过去式,同一段里时态保持一致。

出处:11847-1、401-1、407-1、409-1、3946-1、3947-1

## 10. 主谓一致

- the digital divide **is** threatening(✗ are)。divide 是单数。
- a significant proportion of people **remain**:proportion of + 复数名词,动词用复数也可以。
- **指前面整件事用 this + 单数动词(382-1):** ✗ `These prevent them …` → ✓ `This prevents them …`。
- **单数主语,现在时动词加 s(401-1):**
  - ✗ `If something urgent occur` → ✓ `If something urgent **occurs**`(something、everything、nobody 都是单数)
  - ✗ `the practice is less expensive and improve work efficiency` → ✓ `… and **improves** …`(and 后面的第二个动词也要加 s)
- **people 是复数(401-1):** ✗ `people is` → ✓ `people **are**`。
- **which 指代前面整件事时是单数(407-1,一篇错 3 处):** ✗ `which reduce / make / bring` → ✓ `which **reduces / makes / brings**`。which 不指代最近的复数名词,而是指代「前面整个情况」时,动词一律加 s。
- **动名词 doing 作主语是单数(409-1):** ✗ `visiting these places in person bring …` → ✓ `visiting these places in person **brings** …`。和 407 的 mastering … is 同理。
- **which 指代整件事是单数,连续三篇错(407、409、3946):** 3946-1 一篇出现 2 次 ✗ `which cause` → ✓ `which **causes**`。写完每个 which 从句都回头看动词加 s 没有。

出处:11847-1、382-1、401-1、407-1、409-1、3946-1

## 11. 中文语序 → 英文语序

中文把修饰语放在前面,英文常放在后面,用 of / with / who / on / online 连接。

| 中文 | ✗ 我写的 | ✓ | 出处 |
| --- | --- | --- | --- |
| 与世界各地亲友的即时联系 | global friend and family of instant connec | instant contact **with** friends and family **around the world** | 11847-1 |
| 一种新的社会不平等形式 | a new social unqueite form | a new form **of** social inequality | 11847-1 |
| 不能上网的人 | the peopel who connect not | people **who are not connected** / those **without access** | 11847-1 |
| 在电子设备上玩游戏 | electronic to play games | play games **on electronic devices** | 382-1 |
| 网上的知识和信息 | the online knowledge and information | knowledge and information **online** | 382-1 |
| 人与人之间的交流 | communication between people and people | communication **between people** / human interaction | 382-1 |
| 可能会出现一些问题 | it might occur something | **some problems** might occur | 401-1 |
| 人们很难看清别人的肢体语言 | people is hard to see clearly other's body language | **it is hard for people to** see other people's body language **clearly** | 401-1 |
| 网上会议和培训的普及有更多好处 | online meeting and traning become popularty has more advantage | **the popularity of** online meetings and training **brings** more advantages | 401-1 |
| 越来越多的家长让孩子用电子设备 | there are a growing of parents let children use electronic | **a growing number of** parents **allow** children to use electronic devices | 407-1 |
| 他们会很难理解学习内容 | they will be hard to understand study content | they will **find it difficult to** understand what they are learning | 407-1 |
| 亲眼看实物和在屏幕上看完全不同 | it is completely different between seeing … and looking … | **seeing a real item is completely different from** looking at a picture on a screen | 409-1 |
| 收入来自门票 | income is not only museum tickets | income **comes not only from** museum tickets | 409-1 |
| 需要的劳动力减少 | the labour who need are less | **fewer workers are needed** | 3946-1 |
| 失业率上升 | the employment rate increase | the **unemployment** rate **to rise** | 3946-1 |
| 主动联系外星生物 | contacting actively alien creature | **actively contacting** alien creatures | 3947-1 |
| 本文将先分析两种观点 | This essay analyse both views first | This essay **will analyse** both views first | 3947-1 |

**「某人很难 / 很容易做某事」(401-1):** 不能用人做主语。

✗ `People is hard to see …`
✓ `**It is hard for people to** see …`

同样:It is easy for children to …;It is difficult for elderly people to …

407-1 又错了一次:✗ `they will be hard to understand` → ✓ `they will **find it difficult to** understand`。另一种正确写法是 It is difficult for them to understand …。**连续两篇错同一个句式,必须背熟。**

**「……的普及 / 增加 / 发展」(401-1):** 中文常把一整句当主语(「网上会议普及了」+「有更多好处」),英文一个句子只能有一个谓语,要把前半句变成名词短语:the popularity of …、the increase in …、the development of …。

**副词放在宾语后面:** ✗ `see clearly other people's body language` → ✓ `see other people's body language **clearly**`。

**「在哪方面有优势」要紧跟 edge / advantage(11847-1、11847-2 都错了):**

✗ gain a genuine edge compared with people who are not connected **in employment, study and social life**
✓ gain a genuine edge **in employment, study and social life** compared with people who are not connected

修饰谁,就紧跟谁。

**「A 和 B 不同」(409-1):** 让 A 做主语,用 **A is different from B**,不要写 it is different between A and B。

**近义词语序 / 词义相反要警惕(3946-1):** 中文「需要的劳动力减少」不要逐字翻成 the labour who need are less(labour 不可数、who 不能指 labour),让 workers 做主语用被动:**fewer workers are needed**。另外 **employment = 就业率,unemployment = 失业率**,带 un- 是否定,别写反。

**方式副词放在动词前面(3947-1):** ✗ `contacting **actively** alien creatures` → ✓ `**actively** contacting` alien creatures。同类:seriously consider、greatly improve、widely used。

**双边讨论开头模板(3947-1):** 「本文将先分析……然后提出看法」= **This essay will first analyse both views and then give my own opinion**。essay 是单数,用现在时也要 analyses;开头说「将要做」用 will analyse 最稳。

出处:11847-1、11847-2、382-1、401-1、407-1、409-1、3946-1、3947-1

## 13. 「随着」用 As

✗ `Over the daily life gradually moving forward internet`
✓ `**As** daily life gradually **moves online**`

## 14. 两个句子不能只用逗号连接

两个完整的句子(各有主语和动词)之间,**只放一个逗号是错的**。三种改法:

| 改法 | 例子 |
| --- | --- |
| 逗号 + and / but / so | …need to wear glasses**, and** many doctors link this to … |
| 句号 | …need to wear glasses**.** Many doctors link this to … |
| 分号 | …by-product**;** instead, they should … |

**我写错的:**

| ✗ | ✓ | 出处 |
| --- | --- | --- |
| …shouldn't regard it as xx by-product, **ranther** invest … | …an inevitable by-product; **instead, they should** invest … / **Rather than regarding** it as …, they should invest … | 11847-1 |
| …shouldn't regard it as inevitable by-product**, instead,** they should … | …an inevitable by-product**;** instead, they should … | 11847-2 |
| …primary student need to wear glasses**,** many doctors link … | …primary school students need to wear glasses**, and** many doctors link … | 382-1 |
| …they will become more skilled**, then** they can … | …they will become more skilled**, and then** they can … | 382-1 |
| …a richer experience**, meanwhile** these places also boost … | …a richer experience**, and** these places also boost … | 409-1 |

**instead、then、however、therefore、moreover、meanwhile 都是副词,不是连词**,不能代替 and / but 把两个句子连起来。

出处:11847-1、11847-2、382-1、409-1

## 16. 所有格 's

中文「孩子的眼睛」「孩子的电脑技能」,「的」在英文里要用 **'s**。

| ✗ | ✓ |
| --- | --- |
| children computer skill | **children's** computer skills |
| children eyes | **children's** eyes |
| other's body language(401-1) | **others'** body language / **other people's** body language |
| tourist's hotel stays(409-1) | **tourists'** hotel stays |
| reduce factories cost(3946-1) | reduce **factories'** costs |
| aliens' technology far beyond us(3947-1) | technology far beyond **ours** |

- 不以 s 结尾的名词(包括 children、people、men):加 **'s** → children's、people's。
- 以 s 结尾的复数:只加 **'** → students'、parents'、**others'**。
- 「别人的」通常指很多人,用复数 others',最简单的写法是 other people's。
- **名词性物主代词(3947-1):** mine、yours、his、hers、**ours**、theirs 本身等于「形容词性物主代词 + 名词」,后面不再接名词:✗ `technology far beyond us` → ✓ `technology far beyond **ours**`(= our technology)。us 是宾格,不能表示「我们的东西」。

> 382-1 里 `children's social skill`、`children's physical health`、`children's posture` 你都写对了,结尾段写快了才漏掉。

出处:382-1、401-1、409-1、3946-1、3947-1

## 17. 标点和大小写

- **I** 永远大写(✗ i firmly、i don't)。
- **国家名、城市名首字母大写(382-1):** ✗ `in china` → ✓ `in China`。
- 英文没有顿号「、」,列举用逗号:remote work, online education, remote medicine。
- 逗号紧跟前一个词,后面加空格:✗ `course ,and` → ✓ `courses, and`。
- 句首字母大写:✗ `governemnt and business` → ✓ `Governments and businesses`。
- **句号、逗号后面一定空一格:** ✗ `advantages.Smartphones`、`pandemic,millions`、`example,in`、`downsides.Although` → ✓ `advantages. Smartphones`、`pandemic, millions`、`example, in`、`downsides. Although`。
- 句号前面不空格,也不要连续两个空格:✗ `working at home .` → ✓ `working at home.`。
- **每段最后一句也要有句号(382-1 开头段漏了)。**
- **列举两样东西用 and,不用「、」(401-1):** ✗ `hold meeting、organize training` → ✓ `hold meetings and organize training`。
- **句号 / 逗号后面空一格,句号前面不空格(407-1):** ✗ `grown.Because`、`PowerPoint.Meanwhile`、`Therefor,parent`、`advantage .` → ✓ `grown. Because`、`PowerPoint. Meanwhile`、`Therefore, parents`、`advantage.`。
- **逗号后面的单词不要大写(407-1):** ✗ `Additionally, Playing` → ✓ `Additionally, playing`;但句号后面必须大写:✗ `the various of programs`(句首)→ ✓ `**T**he various programs`。
- **标点后漏空格(409-1 又错 6 处):** ✗ `necessary,because`、`screen.Standing`、`headsets,so`、`museum,go` → ✓ 标点后空一格;也不要留两个空格。
- **because 引导的从句不能单独成句(409-1):** ✗ `I disagree the point. because visiting …` → ✓ `I disagree with this view, because visiting …`。
- **专有名词每个实词首字母大写(409-1):** ✗ `Palace museum` → ✓ `**the Palace Museum**`。
- **正式作文不用缩写(409-1、3946-1、3947-1 连续三篇):** ✗ can't、won't、don't、couldn't、should't → ✓ **cannot、will not、do not、could not、should not**。
- **逗号后面的单词不要大写,句号后面必须大写(3947-1):** ✗ `Secondly, Once` → ✓ `Secondly, once`;✗ `them. while` → ✓ `them. While`。

出处:11847-1、11847-2、382-1、401-1、407-1、409-1、3946-1、3947-1

## 18. 表示结果、目的、原因的连接词

| 中文 | ✓ 用 | 注意 |
| --- | --- | --- |
| 所以(结果) | **so** / as a result, | ✗ `so that company may suffer a large loss` → ✓ `so the company may suffer a large loss` |
| 为了(目的) | **so that** / to do | so that 后面常有 can / will:… update their systems **so that** hackers cannot break in |
| 考虑到这种情况 / 因此 | **For this reason,** / **Therefore,** | ✗ `As a result. I recommend …` → ✓ `For this reason, I recommend …` |

- **so that = 为了**,不是「所以」。表示「所以」只用 so。
- As a result、For this reason、Therefore 后面用**逗号**,和后面的句子连在一起,不能单独加句号。
- As a result 是「结果是」,前面要有原因;401-1 结尾前一句说的是「机密可能被窃取」,后面是「我建议……」,这是「考虑到」,不是「结果」。
- **so that 不能当「所以」用(407-1 又错一次):** ✗ `…, so that cause a lack of social skills` → ✓ `…, **which causes** a lack of social skills`。so that 后面要接完整句子表目的;让 which 指代整件事表结果。
- **「以便不……」用 so that … not(407-1):** ✗ `so children won't be affected` → ✓ `**so that** children won't be negatively affected`。
- **so that 后面必须是完整句子,不能接 doing(409-1):** ✗ `attract tourists so that boosting local economy` → ✓ `attract tourists, **which boosts** the local economy`。**连续三篇在 so / so that 上出错。**
- **讲原因用 This is because,讲结果才用 That is why(409-1):** ✗ `**That is why** people can't get rich experience`(后面是原因)→ ✓ `**This is because** people cannot get the same rich experience`。
- **so that 第 4 次错(3947-1):** ✗ `see humans as a resource **so that attract** Earth` → ✓ `… as a resource, **and then attack** the Earth`。so that 后面必须是「主语 + 动词」的完整句子;两个动作顺承用 and then。另外注意 **attract = 吸引,attack = 攻击**,别混。

出处:401-1、407-1、409-1、3947-1

## 19. 并列结构:neither … nor … 和 not only … but also …

并列连词的关键都是**两边的结构要对称**(名词对名词、动词对动词、介词短语对介词短语)。

### neither … nor …(既不……也不……)

| ✗ | ✓ |
| --- | --- |
| children **neither get** enough opportunities … **nor fouce** on study | children **neither have** enough opportunities … **nor can they focus** on their studies |

- 上句左边是「动词 + 宾语」,右边也要是「动词 + 宾语」;参考范文用了倒装 nor can they focus,语气更强。
- 简单的对称更稳妥:✓ `children neither **have** enough opportunities nor **get** good results`(两边都是动词 + 宾语)。
- **就近原则**:nor 后面的主语决定动词单复数:Neither he nor I **am** wrong. / Neither I nor he **is** wrong.
- 肯定形式是 both … and …;「要么……要么……」是 either … or …,规则相同。

### not only … but also …(不仅……而且……)

| ✗ | ✓ |
| --- | --- |
| income **is** not only museum tickets, but also tourist's hotel stays(409-1) | income **comes not only from** museum tickets, but also **from** tourists' hotel stays |
| employers not only **have to hire** …, but also **bear** the loss …(3946-1) | employers not only **have to hire** …, but also **have to bear** the loss … |

- **not only 前面有什么词(介词、动词),but also 后面也要有对应的词**。第一句来自 409-1:from 放在 not only 前面,两边共用也对;但你原来的句子 income is tickets 逻辑不通,收入不能「是」门票。
- **3946-1 的错法更典型:not only 后面是 have to hire(谓语),but also 后面直接放了动词原形 bear,结构残缺**——要补成 have to bear,两边都是 have to do。有意思的是,这篇的参考范文原句也犯了同样的错(改了 7 处之一),说明这是中国学生的常见坑。
- 连接两个主语时动词就近原则:Not only the students but also the teacher **is** coming.
- 参考范文的改法(409):income comes **not only from** … tickets, **but also from** visitors' hotel stays, meals and souvenirs——两边都是 from + 名词,完全对称。

出处:407-1、409-1、3946-1
